# VibeSec Audit — VidGrab (Dowload-video)

**Date:** 2026-08-05
**Scope:** Full codebase, risk-prioritized pass ahead of first public deploy on Mắt Bão satellite infra
**Stack:** FastAPI + Celery + Supabase (Postgres/Auth) backend, Vite/React frontend, Docker
**Result:** 0 🔴 CRITICAL, 0 🟠 HIGH, 1 🟡 MEDIUM, 0 🟢 LOW

## Scope limitation (read this first)

This is a **risk-prioritized pass**, not an exhaustive line-by-line review of all
~40 API route files. Covered: env/secret handling, hardcoded secrets, SQL
injection patterns, CORS/debug config, Docker secret exclusion, auth middleware
design, and everything touched by today's transcript-translate/ASR feature work
(IDOR checks, path traversal, cue-length caps — see git log around commits
a974218, 4507e1c). Not exhaustively re-verified: authorization logic on every
individual endpoint across the ~26 historical feature phases.

## Findings

### 1. Admin password committed to git history — 🟡 MEDIUM
**Vị trí:** `database/migrations/020_fix_trigger_create_admin.sql`, `021_create_admin_account.sql`
**Vấn đề:** Mật khẩu admin (`thientrieu753@gmail.com`) nằm dạng plaintext trong 2 file SQL, đã push lên GitLab từ trước (không phải do session này tạo ra).
**Fix:** Đổi mật khẩu tài khoản này ngay sau khi xác nhận deploy ổn định (Settings → đổi mật khẩu trong app, hoặc qua Supabase Dashboard → Auth → Users). Không cần sửa file SQL (giữ nguyên cho lịch sử migration), chỉ cần password THẬT không còn khớp với password trong git.

## ✅ Điểm tốt

- Auth middleware (`app/core/auth_middleware.py`): JWT validation ủy quyền hoàn toàn cho Supabase (`supabase.auth.get_user(token)`), không tự decode/verify — tránh các lỗi JWT cổ điển (algorithm confusion, thiếu verify signature). API key so sánh qua SHA-256 hash, không lưu plaintext.
- `.dockerignore` (cả backend + frontend) loại trừ `.env`/`.env.*` khỏi image layers đúng cách.
- Không có wildcard CORS (`allow_origins=["*"]`), không có `DEBUG=True` trong code.
- Không tìm thấy pattern SQL injection (raw f-string vào query) — dùng Supabase client (tự parameterize).
- Không có secret nào lộ qua `import.meta.env.*` phía frontend (chỉ có `import.meta.env.DEV`, built-in an toàn).
- Tính năng mới hôm nay (transcript-translate/ASR) đã tự kiểm IDOR, path-traversal, giới hạn độ dài input — xem commit `a974218`.

## 🎯 Kết luận

**Verdict: pass_with_warnings** — không có gì chặn deploy public. Khuyến nghị đổi mật khẩu admin sau khi deploy ổn định.
